# Пометка реф-колёс в уведомлениях

## Задача

Колёса «для рефералов» ничем не отличаются в уведомлении от обычных —
пользователь узнаёт об этом только после перехода по ссылке. Нужно
помечать такие колёса в уведомлениях и в списке /active.

## Факты (проверено на живом API 2026-07-30)

- У API BetBoom (`get-info`) нет флага «рефовое колесо».
- Отличие только в тексте: у реф-колеса `description` =
  «Розыгрыш фрибетов для рефералов» (обычное: «УЧАСТВУЙ В РОЗЫГРЫШЕ ФРИБЕТОВ»).
- У реф-колеса часто «ref» прямо в slug URL (`/freestream/aunkereref`).

## Детект (два сигнала, OR)

1. **Текст API**: регэксп `\bреф` (регистронезависимо) по `title` +
   `description` — ловит «рефералов», «рефы», «рефовод», «рефка».
   Граница слова отсекает «префикс» и т.п.
2. **Slug URL**: подстрока `ref` в последнем сегменте пути — работает
   при сбое API и при `PRECHECK_WHEELS=false`.

## Изменения

- `betboom.py`:
  - `fetch_wheel_info(url, session) -> dict | None` — выделен из
    `check_wheel_status`; возвращает `info` или `None` при ошибке.
  - `is_referral_wheel(url, info) -> bool` — детект по двум сигналам.
  - `precheck_wheel_status` → `precheck_wheel(url, session=None) ->
    tuple[str, bool]` — (статус, реф-флаг). При попадании в кэш
    expired инфо нет — флаг только по slug.
  - `classify_wheels` проставляет `item["referral"]` каждому колесу
    (сохранённый флаг ИЛИ вычисленный по инфо/slug).
- `parser.py`, `twitch.py`: в entry новое поле `"referral": bool`.
  При `PRECHECK_WHEELS=false` — детект только по slug.
- `telegram_api.py`:
  - одиночное уведомление: строка `⚠️ Колесо для рефералов` после «Ссылка:»;
  - multi-уведомление: к пояснению ссылки добавляется «для рефералов».
- `active_report.py`: в строке колеса пометка `⚠️ рефы`.

## Не меняется

Кулдаун, дедупликация, фильтрация expired — реф-колёса рассылаются
как обычно, меняется только текст.

## Тесты

- `test_betboom.py`: `is_referral_wheel` (текст / slug / ничего),
  `precheck_wheel` возвращает кортеж.
- `test_telegram_api.py`: строка про рефералов есть при флаге, нет без.
- `test_parser.py` / `test_twitch.py`: обновить патчи precheck на кортеж,
  проверить поле `referral` в entry.
