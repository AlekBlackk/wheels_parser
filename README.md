# WheelsParser

Отслеживает публичные Telegram-каналы и Twitch-чаты, находит новые ссылки `betboom.ru/freestream/...`. В Telegram ищутся ссылки и ключевые слова, в Twitch — только ссылки от стримера, модераторов, VIP и ботов. Находки сохраняются локально и рассылаются в Telegram. Бот отвечает на команды.

## Возможности

- мониторинг Telegram-каналов через `https://t.me/s/<channel>` (без Telegram API);
- мониторинг Twitch-чатов через анонимный IRC (без токенов/OAuth), только ссылки от broadcaster/mod/VIP/известных ботов (см. «Twitch»);
- Telegram-уведомления через Bot API, интерактивные команды (`/help`);
- прямые запросы к API BetBoom для проверки статуса колёс (`PRECHECK_WHEELS`) — завершившиеся не рассылаются;
- единая канонизация URL (без query-параметров и завершающего `/`) везде: извлечение, дедупликация, `/active`, кэш;
- дедупликация с кулдауном повторных уведомлений (`REALERT_COOLDOWN_MINUTES`);
- `/removewheel <номер|ссылка>` — скрывает колесо из `/active` до 00:00 МСК, переживает рестарт (`removed_wheels.json`);
- все даты/счётчики — по московскому времени, независимо от таймзоны сервера;
- offset бота в `bot_state.json` — команды не выполняются повторно после рестарта;
- история находок в `freebets.json`, обработанные сообщения в `seen_ids.json`.

## Команды бота

| Команда | Действие |
|---|---|
| `/start` | Приветствие и краткая информация о боте |
| `/active` | Проверка актуальных колёс за сегодня |
| `/removewheel <номер\|ссылка>` | Убрать колесо из `/active` по номеру или ссылке (скрывается до 00:00 МСК); алиас `/delwheel` |
| `/status` | Статистика найденных ссылок |
| `/wheels` | Колёса за последние `WHEELS_WINDOW_MINUTES` минут (по умолчанию 10) |
| `/channels` | Список отслеживаемых каналов |
| `/words` | Список ключевых слов |
| `/addword` | Добавить ключевое слово |
| `/removeword` | Удалить ключевое слово |
| `/add @channel` | Добавить канал в мониторинг (сохраняется в `channels.txt`) |
| `/remove @channel` | Убрать канал из мониторинга (сохраняется в `channels.txt`) |
| `/twitch` | Список отслеживаемых Twitch-каналов |
| `/addtwitch channel` | Добавить Twitch-канал (сохраняется в `twitch_channels.txt`; можно указать логин или ссылку `twitch.tv/логин`) |
| `/removetwitch channel` | Убрать Twitch-канал (сохраняется в `twitch_channels.txt`) |
| `/help` | Список команд и текущие настройки |

## Файлы

Код и редактируемые вручную файлы:

- `wheelsparser/` — код, точка входа `python -m wheelsparser` (структура ниже);
- `tests/` — тесты (`python -m pytest`);
- `pyproject.toml` — зависимости, конфиг ruff/pytest/mypy;
- `run.bat` — установка и запуск в Windows;
- `env.example` — шаблон настроек, скопируйте в `.env`;
- `.env` — локальные настройки и секреты (создайте сами);
- `channels.txt`, `twitch_channels.txt`, `keywords.txt` — списки каналов/слов (создаются автоматически при первом добавлении).

Машинное состояние — в `data/` (путь переопределяется `WHEELSPARSER_DATA_DIR`; при апгрейде переносится из корня само): `freebets.json` (история), `seen_ids.json` (обработанные сообщения), `bot_state.json` (offset бота), `removed_wheels.json` (удалённые из `/active`), `parser.log` (лог с ротацией).

## Быстрый запуск в Windows

1. Установите Python 3.10 или новее.
2. Скопируйте `env.example` в `.env` и заполните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
3. Запустите `run.bat`.

Скрипт сам установит зависимости и запустит парсер.

## Обычный запуск

```bash
python -m pip install -e .
python -m wheelsparser
```

## Настройки

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `TELEGRAM_BOT_TOKEN` | пусто | Токен бота |
| `TELEGRAM_CHAT_ID` | пусто | Чат для уведомлений и команд |
| `WHEELSPARSER_DATA_DIR` | `data/` | Каталог состояния: JSON, лог, lock |
| `WHEELSPARSER_CHANNELS` | встроенный список | Каналы через запятую. Только при первом запуске, если нет `channels.txt`; дальше правда — файл и `/add`, `/remove` |
| `CHECK_INTERVAL` | `60` | Интервал проверки, сек (мин. 10) |
| `REQUEST_TIMEOUT` | `15` | Тайм-аут HTTP-запроса |
| `MESSAGES_PER_CHANNEL` | `50` | Сообщений на канал за проход |
| `MAX_SEEN_PER_CHANNEL` | `2000` | Максимум ID на канал |
| `WHEELS_WINDOW_MINUTES` | `10` | Окно `/wheels`, мин |
| `MAX_RESULTS` | `5000` | Максимум записей `freebets.json` (старые отбрасываются) |
| `ACTIVE_MAX_AGE_HOURS` | `20` | Макс. возраст колеса для `/active`, ч |
| `ACTIVE_CHECK_CONCURRENCY` | `3` | Потоков опроса API BetBoom при `/active` |
| `REALERT_COOLDOWN_MINUTES` | `30` | Кулдаун повтора по URL, мин |
| `PRECHECK_WHEELS` | `true` | Проверять статус колеса перед уведомлением |
| `TWITCH_ENABLED` | `true` | Мониторинг Twitch-чатов |
| `WHEELSPARSER_TWITCH_CHANNELS` | пусто | Twitch-каналы через запятую, только при первом запуске (аналог `WHEELSPARSER_CHANNELS`) |
| `TWITCH_BOTS` | встроенный список | Логины ботов, чьи ссылки принимаются без бейджа мода (по умолчанию nightbot, streamelements, moobot, fossabot, wizebot, streamlabs) |
| `STALE_COMMAND_SECONDS` | `120` | Старые команды подтверждаются, но не выполняются (защита от бэклога) |
| `CHANNEL_FAIL_THRESHOLD` | `5` | Уведомление после N неудачных циклов канала |
| `ALERT_ON_FIRST_RUN` | `false` | Слать находки первого прохода |
| `USE_COLORS` | `true` | Цвет в консоли |
| `USE_ICONS` | `true` | Эмодзи-значки в логе |

В `cmd.exe` эмодзи квадратами → `USE_ICONS=false` (текстовые метки `[OK]`, `[!]`, `[NEW]`) или Windows Terminal. В `parser.log` цветовые коды не пишутся.

## Twitch

Подключение анонимное через IRC (`irc.chat.twitch.tv:6697`, SSL) — без регистрации приложения, токенов, OAuth (штатный режим «анонимных» чат-вьюеров).

- ссылка принимается только от broadcaster, модератора, VIP или бота из `TWITCH_BOTS`;
- та же канонизация URL и проверка статуса (`PRECHECK_WHEELS`), запись в `freebets.json` с `"source": "twitch"`;
- кулдаун `REALERT_COOLDOWN_MINUTES` общий с Telegram — дубль не рассылается;
- уведомление уходит сразу, не дожидаясь цикла Telegram;
- автопереподключение при обрыве (backoff 5–120 сек); `/addtwitch`, `/removetwitch` применяются на лету;
- у IRC нет истории — читаются только сообщения, пришедшие при запущенном парсере.

## Время

Все даты — по московскому времени (UTC+3, без перехода на летнее): `found_at`, счётчики `/status`, окно `/wheels`, суточный сброс `/active` в 00:00 МСК. Таймзона сервера не влияет.

## Формат данных

Запись `freebets.json`: URL, время обнаружения, канал, ID и URL сообщения, фрагмент текста, результат отправки.
URL канонический: без query-параметров, без завершающего `/`, домен в нижнем регистре без `www` — разные хвосты одной ссылки схлопываются в одну запись.
Повтор того же URL подавляется на `REALERT_COOLDOWN_MINUTES` (по умолчанию 30 мин), затем уведомление уходит снова — колёса живут на постоянных адресах, один URL может означать новый запуск. При `PRECHECK_WHEELS` завершившиеся колёса молча пропускаются.

`bot_state.json` хранит `update_id` бота, пишется атомарно после каждой пачки команд — после рестарта повтора не будет. При повреждении файла offset сбрасывается на 0, от старого бэклога защищает `STALE_COMMAND_SECONDS`.
